NOTA IMPORTANTE — Compatibilidad con datasets existentes
================================================================================
Los datasets grabados ANTES de estos cambios tienen features llamadas
"object_pos_x", "object_quat_w", etc. Los datasets NUEVOS tendrán
"obj0_pos_x", "obj0_quat_w", etc.

replay_mujoco.py sigue usando set_cube_pose() que ahora es un wrapper
legacy — funciona sin cambios para datasets viejos.

Para reproducir datasets viejos con el código nuevo, replay_mujoco.py
busca "object_pos_x" en las features del dataset, lo cual seguirá
funcionando porque lee el dataset tal cual fue grabado.
